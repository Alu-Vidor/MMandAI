# Математическое моделирование и ИИ

Сайт для абитуриентов кафедры математики ИФМиКН РГУ имени С.А. Есенина. Статический HTML/CSS/JavaScript, без сборки и серверной части.

## Запуск

Откройте `index.html` или запустите `python -m http.server 8000` в папке проекта и перейдите на `http://localhost:8000`.

## GitHub Pages

1. Сохраните изменения и отправьте их в ветку `main` репозитория `Alu-Vidor/MMandAI`.
2. В GitHub: **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` опубликует сайт. Если изменения были отправлены до включения Pages, запустите **Actions → Deploy to GitHub Pages → Run workflow**.
4. Ожидаемый адрес после успешной публикации: `https://alu-vidor.github.io/MMandAI/`.

Альтернатива: **Deploy from a branch → main → /(root)**. Относительные ссылки поддерживают подкаталог GitHub Pages и локальное открытие.

## Источники и редактирование

Специальность: 01.05.01 «Фундаментальные математика и механика». Профиль по титулу плана: «Математическое моделирование и искусственный интеллект». Очный специалитет, 5 лет. Квалификация: «Математик. Механик. Преподаватель». Год начала подготовки в плане — 2027; это поле плана, а не подтверждение открытой приёмной кампании.

Актуальные источники: учебный план `01_05_01_Fundamentalnaya_matematika_i_mekhanika_23_10_26_na_soglasovanie_s_KM_plx.xlsx` из папки `Учебный план`, лист `ПланСвод`; действующие РПД из `rpd__doc_docx`, программы практик из `pp__doc_docx`, ГИА из `gia__doc_docx` и компетентностная модель от 23.10.2026. Сайт актуализирован 26.10.2026. Названия, коды, семестры, часы и зачётные единицы читаются непосредственно из УП. Проверяется объём 300 з.е., включая 27 з.е. практик. Обе альтернативы каждой пары по выбору показаны, но при проверке нагрузки учитывается один вариант.

На диаграмме 58 позиций: отдельные дисциплины, обе альтернативы каждой пары по выбору, факультативы, четыре практики и ВКР. Модули и промежуточные итоги не дублируются. Не суммируйте кредиты обеих альтернатив как обязательную нагрузку.

Описания, связи курсов с результатами и примеры — редакционные пояснения для абитуриентов, а не буквальная таблица соответствий компетенций. Условия приёма, места и стоимость не выдуманы.

Контент: `data.js`. Разметка: `index.html`. Дизайн: `style.css`. Интерактивность: `app.js`. Скрипт `tools/build_data.py` обновляет данные из актуального УП и переназначает ссылки на дисциплины по названиям. Описания хранятся в `tools/course_content.json`, профессиональные задачи — в `tools/practical_examples.json`. Путь к другой версии плана задаётся аргументом `--plan`. Скрипт не меняет исходные документы и не нужен для работы сайта.

## Чёрная дыра

Первый экран содержит интерактивную схематическую визуализацию аккреционного диска на Canvas. Масса задаётся в солнечных массах; радиус горизонта рассчитан по формуле Шварцшильда `2GM/c²`, приблизительно 2,953 км на солнечную массу. Изображение тени и диска, вторичная дуга и линии света визуализируются приближённо, без релятивистской трассировки лучей. Размер тени в пикселях выбран для читаемости и не является шкалой километров. Пояснение доступно внутри виджета.

Физическая идея диска и искривления света проверена по [материалу NASA](https://www.nasa.gov/universe/nasa-visualization-shows-a-black-holes-warped-world/). Изображения NASA не используются. Анимация приостанавливается вне экрана и в скрытой вкладке; при `prefers-reduced-motion` по умолчанию выключена. Код виджета — `black-hole.js`.
