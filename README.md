# Математическое моделирование и ИИ

Сайт для абитуриентов кафедры математики ИФМиКН РГУ имени С.А. Есенина. Статический HTML/CSS/JavaScript, без сборки и серверной части.

## Запуск

Откройте `index.html` или запустите `python -m http.server 8000` в папке проекта и перейдите на `http://localhost:8000`.

## GitHub Pages

1. Сохраните изменения и отправьте их в ветку `main` репозитория `Alu-Vidor/MMandAI`.
2. В GitHub: **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` опубликует сайт. Если изменения были отправлены до включения Pages, запустите **Actions → Deploy to GitHub Pages → Run workflow**.
4. Ожидаемый адрес после успешной публикации: `https://alu-vidor.github.io/MMandAI/`.

Альтернатива: **Deploy from a branch → main → /(root)**. Относительные ссылки поддерживают подкаталог GitHub Pages и локальное открытие.

## Источники и редактирование

Специальность: 01.05.01 «Фундаментальные математика и механика». Профиль по титулу плана: «Математическое моделирование и искусственный интеллект». Очный специалитет, 5 лет. Квалификация: «Математик. Механик. Преподаватель». Год начала подготовки в плане — 2027; это поле плана, а не подтверждение открытой приёмной кампании.

Актуальные источники: учебный план `01.05.01_ИФМКН_ФундМатМех_МатМодИскИнтел_30.10.2026_final.plx.xlsx` из папки `Учебный план+`, лист `ПланСвод`; действующие РПД из `rpd__doc_docx`, программы практик из `pp__doc_docx`, ГИА из `gia__doc_docx` и компетентностная модель от 23.10.2026. Сайт актуализирован 11.11.2026. Названия, коды, семестры, часы и зачётные единицы читаются непосредственно из УП. Проверяется объём 300 з.е., включая 27 з.е. практик. Обе альтернативы каждой пары по выбору показаны, но при проверке нагрузки учитывается один вариант.

На диаграмме 58 позиций: отдельные дисциплины, обе альтернативы каждой пары по выбору, факультативы, четыре практики и ВКР. Модули и промежуточные итоги не дублируются. Не суммируйте кредиты обеих альтернатив как обязательную нагрузку.

Описания, связи курсов с результатами и примеры — редакционные пояснения для абитуриентов, а не буквальная таблица соответствий компетенций. Условия приёма, места и стоимость не выдуманы.

Контент: `data.js`. Разметка: `index.html`. Дизайн: `style.css`. Интерактивность: `app.js`. Скрипт `tools/build_data.py` обновляет данные из актуального УП и переназначает ссылки на дисциплины по названиям. Описания хранятся в `tools/course_content.json`, профессиональные задачи — в `tools/practical_examples.json`. Путь к другой версии плана задаётся аргументом `--plan`. Скрипт не меняет исходные документы и не нужен для работы сайта.

## Чёрная дыра

Звёздное поле, аккреционный диск и светящееся кольцо рисует фрагментный шейдер WebGL из `assets/black-hole-shader.js`. При недоступности или потере контекста WebGL модель переключается на Canvas 2D.

Первый экран содержит интерактивную схематическую визуализацию аккреционного диска. Описание программы и переходы к поступлению и учебному плану предшествуют модели в порядке чтения; параметры эксперимента на узких экранах по умолчанию свёрнуты. Масса задаётся в солнечных массах; радиус горизонта рассчитан по формуле Шварцшильда `2GM/c²`, приблизительно 2,953 км на солнечную массу. Изображение тени и диска, вторичная дуга и линии света визуализируются приближённо, без релятивистской трассировки лучей. Размер тени в пикселях выбран для читаемости и не является шкалой километров. Пояснение доступно внутри виджета.

Физическая идея диска и искривления света проверена по [материалу NASA](https://www.nasa.gov/universe/nasa-visualization-shows-a-black-holes-warped-world/). Изображения NASA не используются. Анимация приостанавливается вне экрана и в скрытой вкладке; при `prefers-reduced-motion` по умолчанию выключена. Код виджета — `black-hole.js`.

## Вакансии

GitHub Actions запускает `tools/refresh_vacancies.py` ежедневно в 09:17 по Москве, при отправке изменений в `main` и при ручном запуске. Скрипт получает вакансии из RSS поиска HH.ru и открытых списков работодателей [Greenhouse](https://docs.greenhouse.io/job-board.html) и [Ashby](https://developers.ashbyhq.com/docs/public-job-posting-api). Список объявлений генерируется в `vacancies.json`.

Время проверки хранится отдельно для каждого источника. Если запрос не удался, сайт показывает последнюю успешную выборку не старше 48 часов. Этот срок учитывает задержки ежедневного запуска.

После публикации GitHub Actions сохраняет обновлённый `vacancies.json` в ветке `codex/vacancy-feed`. Эти коммиты создают регулярную активность в репозитории, чтобы расписание продолжало работать после 60 дней без ручных изменений. Используется встроенный `GITHUB_TOKEN` с правом записи только в задании архивации. [Правила GitHub для расписаний](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/disable-and-enable-workflows)

Для локальной проверки выполните `python tools/refresh_vacancies.py vacancies.json` и откройте сайт через локальный HTTP-сервер.
