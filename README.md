# Математическое моделирование и ИИ

Сайт для абитуриентов кафедры математики ИФМиКН РГУ имени С.А. Есенина. Статический HTML/CSS/JavaScript, без сборки и серверной части.

## Запуск

Откройте `index.html` или запустите `python -m http.server 8000` в папке проекта и перейдите на `http://localhost:8000`.

## GitHub Pages

1. Сохраните изменения и отправьте их в ветку `main` репозитория `Alu-Vidor/MMandAI`.
2. В GitHub: **Settings → Pages → Build and deployment → Source → GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` опубликует сайт. Если изменения были отправлены до включения Pages, запустите **Actions → Deploy to GitHub Pages → Run workflow**.
4. Ожидаемый адрес после успешной публикации: `https://alu-vidor.github.io/MMandAI/`.

Альтернатива: **Deploy from a branch → main → /(root)**. Относительные ссылки поддерживают подкаталог GitHub Pages и локальное открытие.

## Источники и редактирование

Специальность: 01.05.01 «Фундаментальные математика и механика». Профиль по титулу плана: «Математическое моделирование и методы искусственного интеллекта». Очный специалитет, 5 лет. Квалификация: «Математик. Механик. Преподаватель». Год начала подготовки в плане — 2027; это поле плана, а не подтверждение открытой приёмной кампании.

Источники: учебный план `01.05.01 Фундаментальная математика и механика (01.10.26).plx.xlsx`, лист `ПланСвод`; 41 итоговая РПД и реестр из `РПД_2026_итоговые`; компетентностная модель от 01.10.2026. Семестры всех 41 РПД автоматически сверены с учебным планом.

На диаграмме 58 позиций: отдельные дисциплины, обе альтернативы каждой пары по выбору, факультативы, четыре практики и ВКР. Модули и промежуточные итоги не дублируются. Не суммируйте кредиты обеих альтернатив как обязательную нагрузку.

Описания, связи курсов с результатами и примеры — редакционные пояснения для абитуриентов, а не буквальная таблица соответствий компетенций. Для общих курсов, практик и ВКР использован учебный план; отдельные РПД этих позиций в комплекте отсутствуют. Условия приёма, места и стоимость не выдуманы.

Контент: `data.js`. Разметка: `index.html`. Дизайн: `style.css`. Интерактивность: `app.js`. Скрипты в `tools/` извлекают локальные источники; для сайта не нужны. `build_data.py` заменяет данные при повторном запуске.
