# Служебные проверки

`build_data.py` читает актуальный файл из `C:/Users/danii/Desktop/РПД/МатМодиИИ/Учебный план` и формирует `data.js`. При нескольких файлах укажите нужный через `--plan`. Требует openpyxl. Исходные документы не изменяет. Данные берутся с листа `ПланСвод`, для физкультуры без зачётных единиц семестры определяются по формам контроля. Сумма обязательной нагрузки и одного варианта каждой пары по выбору проверяется на 300 з.е., практик — на 27 з.е.

`course_content.json` хранит описания и назначение дисциплин; `practical_examples.json` — профессиональные задачи. Неиспользуемые описания не подставляются вместо новых: неизвестное название останавливает обновление. Ссылки из проектов и интерактивной модели переназначаются по названиям дисциплин. `extract_sources.py` относится к первичному комплекту 01.10.2026 и для актуализации сайта не используется.

`verify_site.cjs` — выполненная проверка браузером Playwright через установленный Edge. Проверены 58 позиций, поиск, фильтрация, карточки и Escape, изменение модели, загрузка логотипов, мобильная ширина, увеличение текста. Путь к Playwright соответствует среде создания; на другом компьютере замените импорт своим установленным Playwright. Для работы сайта эти инструменты не нужны.
